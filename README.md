# AdoptHub

CS383 group project: Animal Adoption System.

## Project Overview

AdoptHub is a proposed system to help people find animals available for adoption and help shelter staff manage adoption applications and animal records.

## Planned Features

- Browse and search animals available for adoption.
- View animal profiles, including health information.
- Submit an adoption application and track its status.
- Review applications and manage animal records as shelter staff.
- Schedule meet-and-greet visits.

## Repository Structure

- `docs/meetings/agendas/` — meeting agendas in PDF format.
- `docs/meetings/minutes/` — detailed meeting minutes and attendance in PDF format.
- `docs/SRS/` — Software Requirements Specification.
- `docs/SDD/` — Software Design Document.
- `diagrams/` — system diagrams and their source files.
- `presentation/` — project presentation.
